# GenAI Tutorial - Python Programs

This folder contains standalone Python programs for all 17 GenAI concepts.

## Modules

1. **01_introduction_to_ai.py** - What is AI and why it matters
2. **02_machine_learning_basics.py** - Teaching computers to learn
3. **03_neural_networks.py** - Brain-inspired computing
4. **04_deep_learning.py** - Many layers of learning
5. **05_nlp.py** - Natural Language Processing
6. **06_computer_vision.py** - Teaching computers to see
7. **07_generative_ai.py** - Creating new content (GANs, VAEs, Diffusion)
8. **08_transformers.py** - The magic behind modern AI
9. **09_llms.py** - Large Language Models (ChatGPT, Claude)
10. **10_prompt_engineering.py** - Talking to AI effectively
11. **11_rag.py** - Retrieval-Augmented Generation
12. **12_fine_tuning.py** - Customizing AI models
13. **13_frameworks.py** - Tools for building AI
14. **14_reinforcement_learning.py** - Learning from rewards
15. **15_ethics.py** - AI Ethics & Safety
16. **16_applications.py** - AI in the real world
17. **17_agents.py** - Autonomous AI systems

## How to Run

Each program can be run independently:

```bash
python 01_introduction_to_ai.py
python 02_machine_learning_basics.py
# ... etc
```

## Requirements

Basic programs work with Python standard library. For advanced features:

```bash
pip install torch torchvision tensorflow
pip install transformers langchain openai
pip install scikit-learn numpy pandas
pip install opencv-python pillow
pip install stable-baselines3 gymnasium
```

## Learning Path

Start with Module 01 and progress through each module in order. Each program includes:
- Explanations of key concepts
- Interactive demos (where applicable)
- Code examples you can modify and experiment with

Happy Learning!
